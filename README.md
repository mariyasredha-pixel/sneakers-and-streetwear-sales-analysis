👟 Sneakers and Streetwear Sales Analysis – Power BI Dashboard
📌 Project Overview

The Sneakers and Streetwear Sales Analysis project is an interactive Power BI dashboard developed to analyze sales performance of sneakers and streetwear products across different product types, brands, categories, countries, genders, and months.

The objective of this project is to transform raw sales data into meaningful and visually understandable insights using data cleaning, data transformation, DAX calculations, KPIs, and interactive visualizations.

The dashboard allows users to explore sales performance through interactive filters for Product Type and Brand, making it easier to identify high-performing products, brands, categories, and markets.

🎯 Project Objectives
Analyze overall sales performance.
Identify the best-performing product types.
Compare sales performance across different brands.
Analyze sales by product category.
Understand gender-wise sales distribution.
Compare sales across different countries.
Analyze monthly sales trends.
Create an interactive and user-friendly Power BI dashboard.
Present business insights in a clear and visually appealing format.

Sneakers generated the highest sales at $81.59K, followed by Hoodies with $63.11K.
